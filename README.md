# Telco-Customer-Churn-ML-Project
This project uses machine learning to forecast customer attrition for a telecom provider. In order to find trends connected to churn, the dataset contains customer demographics, account details, and service usage data. Two models were created after the data was cleaned and encoded: a Random Forest classifier and a Decision Tree classifier. With the highest accuracy, recall, and overall balance between precision and recall, the Random Forest model outperformed the others and was more successful in predicting which customers were most likely to depart. Using Python, Pandas, Scikit-learn, and Seaborn, this project showcases real-world expertise in data preprocessing, feature engineering, model evaluation, and performance visualization.
